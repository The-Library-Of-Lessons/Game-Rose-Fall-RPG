# Rosefall Reborn — Character Overhaul Offline

This package contains the complete game in one playable HTML file, including the redesigned hero, 38 unique NPCs, 33 enemy and boss designs, item drops, combat effects, 16 regions, and 62 quests.

## Android phone or tablet

1. Extract `Rosefall-Reborn-Definitive-v3-Offline.zip` completely.
2. Open the extracted folder.
3. Tap `PLAY_ROSEFALL.html` and choose Chrome, Edge, Firefox, or another full browser.
4. Rotate the device to landscape and tap **New journey** or **Continue**.

Do not play from inside the ZIP preview. If the Files app uses a basic HTML viewer, choose **Open with** and select a full browser.

## Windows, macOS, or Linux

1. Extract the ZIP completely.
2. Double-click `PLAY_ROSEFALL.html`.
3. Use browser full-screen mode for the best experience.

## Controls

| Action | Mobile | Keyboard |
| --- | --- | --- |
| Move | Left joystick | WASD or arrow keys |
| Attack | Sword button | J |
| Rose Arc | Crosshair button | K |
| Thorn Nova | Spark button | L |
| Lumen Dash | Bolt button | R |
| Dodge | Arrow button | Space |
| Talk | Contextual Talk button | E |
| Potion | Potion button | 1 |
| Inventory | Bag button | I |
| Quests | Objective tracker | Q |

Progress saves locally in the browser. Keep using the same file location and browser. Online and offline saves are separate.
